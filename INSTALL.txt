N K HOTEL OS — MOVE ALL PAGES INTO PERSISTENT LAYOUT

CONFIRMED PROBLEM

/dashboard is located at:
app/(os)/dashboard/page.tsx

But Calendar is located at:
app/calendar/page.tsx

Therefore only Dashboard receives:
app/(os)/layout.tsx

The other routes use their own old OSPageShell, so the global center MENU clip
cannot control them.

THIS SCRIPT MOVES ALL PROTECTED ROUTES INTO app/(os).

The URLs do not change because folders in parentheses are Next.js route groups.

Examples:

app/calendar/page.tsx
becomes
app/(os)/calendar/page.tsx

The browser URL remains:
/calendar

INSTALL

1. Extract this ZIP into:

E:\NK Labs\NK Hotel OS

2. Run:

Set-Location "E:\NK Labs\NK Hotel OS"

.\move-all-pages-into-os-layout.ps1

npm run build

3. After the build succeeds:

git add .
git commit -m "Move all Hotel OS pages into persistent layout"
git push origin main
