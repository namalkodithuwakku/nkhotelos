N K HOTEL OS - NKH DASHBOARD CALENDAR COLORS

This update changes only Calendar booking-source colors.

PALETTE

FIT            - mustard gold
Booking.com    - deep muted blue
Expedia        - warm burnt orange
Agoda          - earthy taupe brown
Airbnb         - muted rose
Travel Agent   - deep green
Blocked        - dark charcoal

A subtle highlight remains on each booking card.

INSTALL

1. Extract this ZIP into:

E:\NK Labs\NK Hotel OS

2. Run:

Set-Location "E:\NK Labs\NK Hotel OS"

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

.\install-nkh-dashboard-calendar-colors.ps1

3. Build:

Remove-Item ".next" -Recurse -Force -ErrorAction SilentlyContinue

npm run build

4. Push:

git add .
git commit -m "Apply NKH Dashboard booking colors to Hotel OS calendar"
git push origin main

After the script runs successfully, it can be deleted.
