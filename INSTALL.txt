N K HOTEL OS - SOFT AURORA CALENDAR COLORS

This update changes only Calendar booking colors and shadows.

PALETTE

FIT            - warm golden yellow with charcoal text
Booking.com    - muted teal blue
Expedia        - soft burnt orange
Agoda          - dusty purple
Airbnb         - muted rose
Travel Agent   - olive green
Blocked        - charcoal plum

A subtle aurora highlight is added to the upper-left of each booking card.

INSTALL

1. Extract this ZIP into:

E:\NK Labs\NK Hotel OS

2. Run:

Set-Location "E:\NK Labs\NK Hotel OS"

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

.\install-soft-aurora-calendar-colors.ps1

3. Build:

Remove-Item ".next" -Recurse -Force -ErrorAction SilentlyContinue

npm run build

4. Push:

git add .
git commit -m "Apply soft aurora colors to calendar bookings"
git push origin main

After the script runs successfully, it can be deleted.
