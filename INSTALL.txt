- Improves selected room chips.

- Improves Booking.com, Agoda, Airbnb, Expedia, FIT, Travel Agent and Block colors.

INSTALL

1. Extract into:

E:\NK Labs\NK Hotel OS

2. Run the SQL file in Supabase SQL Editor:

supabase\NK_Hotel_OS_Convert_Direct_To_FIT.sql

3. Run PowerShell:

Set-Location "E:\NK Labs\NK Hotel OS"

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

.\install-calendar-fit-premium-ui.ps1

4. Build:

Remove-Item ".next" -Recurse -Force -ErrorAction SilentlyContinue

npm run build

5. Push:

git add "app/components/calendar" "app/api/calendar/bookings/route.ts" "app/**/*.css" "supabase/NK_Hotel_OS_Convert_Direct_To_FIT.sql"
git commit -m "Upgrade calendar booking UI and standardize FIT source"
git push origin main
