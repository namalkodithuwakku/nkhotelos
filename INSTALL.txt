N K HOTEL OS - SOFT CALENDAR COLOR UPDATE

This update changes only the booking-source colors.

Final colors:

FIT            - soft golden yellow
Booking.com    - soft blue
Expedia        - muted orange
Agoda          - soft purple
Airbnb         - muted rose
Travel Agent   - soft green
Blocked        - muted charcoal purple

INSTALL

1. Extract this ZIP into:

E:\NK Labs\NK Hotel OS

2. Run:

Set-Location "E:\NK Labs\NK Hotel OS"

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

.\install-soft-calendar-colors.ps1

3. Build:

Remove-Item ".next" -Recurse -Force -ErrorAction SilentlyContinue

npm run build

4. Push:

git add .
git commit -m "Apply soft booking colors to calendar"
git push origin main

After the script runs successfully, it can be deleted.
